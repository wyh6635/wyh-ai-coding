## 一、接口规范

### 1.1 通用说明

| 项目 | 说明 |
|------|------|
| 协议 | HTTP/HTTPS |
| 数据格式 | JSON |
| 字符编码 | UTF-8 |
| 跨域支持 | 支持 CORS |
| 认证方式 | Bearer Token（JWT） |

### 1.2 统一响应格式

```json
{
  "code": 200,
  "msg": "success",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 业务状态码（200-成功，400-参数错误，401-未认证，404-资源不存在，500-服务器错误） |
| msg | string | 响应消息 |
| data | any | 业务数据 |

### 1.3 认证规范

| 项目 | 说明 |
|------|------|
| 认证方式 | Authorization: Bearer {token} |
| Token 获取 | 登录接口返回 |
| Token 有效期 | 24 小时 |
| Token 格式 | Base64载荷.SHA-256签名 |
| 传递方式 | 所有需认证接口在请求头携带 |

### 1.4 错误码规范

| 业务码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未登录或 Token 失效 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 二、认证接口

### 2.1 获取验证码

| 项目 | 说明 |
|------|------|
| 接口 | `GET /api/auth/captcha` |
| 认证 | 无需认证 |
| 说明 | 获取图形验证码 |

**请求参数**

无

**响应数据**

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "captcha_key": "string (验证码唯一标识)",
    "captcha_img": "data:image/png;base64,..."
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| captcha_key | string | 验证码唯一标识，登录时需携带 |
| captcha_img | string | 验证码图片（Base64 编码，data URI 格式） |

---

### 2.2 用户登录

| 项目 | 说明 |
|------|------|
| 接口 | `POST /api/auth/login` |
| 认证 | 无需认证 |
| 说明 | 账号密码登录 |

**请求参数**

```json
{
  "username": "string (必填，用户名)",
  "password": "string (必填，密码)",
  "captcha": "string (必填，验证码)",
  "captcha_key": "string (必填，验证码Key)"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | string | 是 | 登录用户名 |
| password | string | 是 | 登录密码 |
| captcha | string | 是 | 图形验证码内容 |
| captcha_key | string | 是 | 验证码 Key（获取验证码接口返回） |

**响应数据**

```json
{
  "code": 200,
  "msg": "登录成功",
  "data": {
    "token": "string (JWT Token)",
    "user": {
      "id": 1,
      "username": "admin",
      "real_name": "系统管理员",
      "avatar": null,
      "email": "admin@edu.cn",
      "phone": "13800000000",
      "role": "admin",
      "status": 1
    }
  }
}
```

**异常场景**

| 业务码 | 场景 |
|--------|------|
| 400 | 请求参数格式错误 |
| 400 | 验证码已过期 |
| 400 | 验证码错误 |
| 400 | 用户名或密码错误 |
| 400 | 账号已被禁用 |

| 业务码 | 场景 |
