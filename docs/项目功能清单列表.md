# 校园信息管理系统 - 项目功能清单

> 版本：v1.0.0
> 技术栈：FastAPI + Vue 3 + Element Plus + MySQL 8.0+
> 生成日期：2026-08-16

---

## 一、系统概览

校园信息管理系统面向院校管理人员，提供学员信息、科目、成绩的全生命周期管理，包含数据看板、多条件查询、用户权限等功能。系统采用前后端分离架构，后端 FastAPI 提供 RESTful API，前端 Vue 3 + Element Plus 实现响应式界面。

## 二、功能菜单层级清单

### 登录

- 图形验证码生成
  - 使用 Pillow 生成 4 位字符验证码
  - 返回 base64 图片 + 验证码 Key
  - 验证码缓存有效期 5 分钟
- 账号密码登录
  - 用户名 + 密码 + 验证码三重校验
  - 密码经 SHA-256 + 盐值加密比对
  - 登录成功返回 JWT Token 及用户信息
- Token 鉴权
  - 自实现 Token 机制（Base64 载荷 + SHA-256 签名）
  - Token 有效期 24 小时
  - 登录状态持久化
  - 路由守卫（未登录自动跳转登录页）
- 退出登录
  - 清除本地 Token
  - 跳转回登录页
- 登录日志记录
  - 登录成功自动更新最后登录时间
- 账号安全校验
  - 校验账号启用/禁用状态
  - 禁用账号拒绝登录
