# PRD-08：个人信息与密码

> 所属系统：校园信息管理系统
> 优先级：P1
> 负责人：产品/前端/后端

---

## 一、模块概述

个人信息模块用于用户查看和修改自己的基本资料，修改密码模块用于更新登录密码，保障账号安全。

## 二、功能需求

### 2.1 个人信息查看

| 项目 | 说明 |
|------|------|
| 需求描述 | 展示当前登录用户的个人信息 |
| 展示字段 | 账号、姓名、头像、邮箱、手机号、角色 |
| 数据来源 | 根据 Token 解析 user_id 查询用户表 |
| 权限要求 | 需登录状态 |

### 2.2 个人信息修改

| 项目 | 说明 |
|------|------|
| 需求描述 | 修改当前用户的个人资料 |
| 可修改字段 | 真实姓名、邮箱、手机号 |
| 校验规则 | 1. 邮箱格式校验（必须包含 @）<br>2. 手机号格式校验（11 位） |
| 不可修改 | 用户名、角色、头像（本期不支持） |

### 2.3 修改密码

| 项目 | 说明 |
|------|------|
| 需求描述 | 修改当前用户的登录密码 |
| 输入字段 | 原密码、新密码、确认新密码 |
| 校验规则 | 1. 原密码必须正确<br>2. 新密码长度不少于 6 位<br>3. 新密码经 SHA-256 + 盐值加密存储 |
| 安全要求 | 1. 修改成功后建议重新登录<br>2. 密码不回显 |

## 四、字段说明

### 4.1 个人信息字段

| 字段 | 类型 | 可修改 | 校验规则 |
|------|------|--------|----------|
| username | VARCHAR(50) | 否 | — |
| real_name | VARCHAR(50) | 是 | 可修改 |
| avatar | VARCHAR(255) | 否 | — |
| email | VARCHAR(100) | 是 | 必须包含 @ |
| phone | VARCHAR(20) | 是 | 11 位 |
| role | VARCHAR(30) | 否 | — |

### 4.2 密码修改字段

| 字段 | 类型 | 校验规则 |
|------|------|----------|
| old_password | VARCHAR | 必须与数据库密码匹配 |
| new_password | VARCHAR | 长度 ≥ 6 位 |

## 五、接口定义

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 获取个人信息 | GET | `/api/users/profile` | 获取当前用户资料 |
| 修改个人信息 | PUT | `/api/users/profile` | 更新用户资料 |
| 修改密码 | POST | `/api/users/change-password` | 更新登录密码 |

## 六、业务规则汇总

| 规则 | 说明 |
|------|------|
| 登录校验 | 所有接口需登录状态 |
| 邮箱格式 | 必须包含 @ 符号 |
| 手机号格式 | 必须为 11 位数字 |
| 密码长度 | 新密码不少于 6 位 |
| 原密码校验 | 修改密码必须验证原密码 |
| 密码加密 | 使用 SHA-256 + 盐值加密存储 |
