# PRD-01：登录模块

> 所属系统：校园信息管理系统
> 优先级：P0
> 负责人：产品/前端/后端

---

## 一、模块概述

登录模块是系统的入口，负责用户身份认证与安全校验，确保只有合法用户才能访问系统功能。支持图形验证码、账号密码、Token 鉴权等多重安全机制。

## 二、功能需求

### 2.1 图形验证码生成

| 项目 | 说明 |
|------|------|
| 需求描述 | 用户访问登录页时，系统自动生成图形验证码，用于防止暴力破解 |
| 触发时机 | 登录页加载时自动请求 |
| 输入参数 | 无 |
| 输出内容 | 验证码图片（base64 格式）、验证码 Key |
| 业务规则 | 1. 验证码为 4 位字符（字母+数字）<br>2. 验证码有效期 5 分钟<br>3. 验证码使用后立即失效<br>4. 支持点击刷新验证码 |
| 异常处理 | 接口异常时前端显示默认占位图 |

### 2.2 账号密码登录

| 项目 | 说明 |
|------|------|
| 需求描述 | 用户通过用户名、密码、验证码进行登录 |
| 前置条件 | 用户已获取有效验证码 |
| 输入参数 | 用户名（username）、密码（password）、验证码（captcha）、验证码 Key（captcha_key） |
| 业务规则 | 1. 用户名不能为空<br>2. 密码不能为空<br>3. 验证码必须匹配且在有效期内<br>4. 密码经 SHA-256 + 盐值加密后与数据库比对<br>5. 账号状态为禁用时拒绝登录<br>6. 登录成功返回 Token 与用户信息 |
| 输出内容 | Token、用户基本信息（ID、用户名、姓名、头像、邮箱、手机号、角色、状态） |
| 异常场景 | 验证码过期、验证码错误、用户名或密码错误、账号被禁用、参数格式错误 |

### 2.3 Token 鉴权

| 项目 | 说明 |
|------|------|
| 需求描述 | 登录成功后系统生成 Token，后续请求通过 Token 验证用户身份 |
| Token 结构 | Base64 载荷（用户信息 JSON） + "." + SHA-256 签名 |
| 载荷内容 | user_id、username、role、exp（过期时间戳） |
| 有效期 | 24 小时 |
| 验证规则 | 1. Token 格式校验<br>2. 签名完整性校验<br>3. 过期时间校验<br>4. 用户存在性校验 |
| 前端处理 | 1. 登录成功存储 Token 到本地<br>2. 每次请求自动注入 Authorization Header<br>3. Token 过期自动跳转登录页 |

### 2.4 退出登录

| 项目 | 说明 |
|------|------|
| 需求描述 | 用户主动退出系统，清除登录状态 |
| 触发时机 | 点击"退出登录"按钮 |
| 业务规则 | 1. 清除本地存储的 Token<br>2. 清除本地存储的用户信息<br>3. 跳转到登录页 |

### 2.5 登录日志

| 项目 | 说明 |
|------|------|
| 需求描述 | 登录成功后自动记录用户最后登录时间 |
| 业务规则 | 每次登录成功更新 `user.last_login_time` 字段 |

## 三、页面原型

```
+----------------------------------------+
|            校园信息管理系统              |
+----------------------------------------+
|  [ Logo ]                              |
|                                        |
|  +----------------------------------+  |
|  | 用户名 [____________________]    |  |
|  +----------------------------------+  |
|                                        |
|  +----------------------------------+  |
|  | 密码   [____________________]    |  |
|  +----------------------------------+  |
|                                        |
|  +----------------+  +--------------+  |
|  | 验证码 [_____] |  | [验证码图片] |  |
|  +----------------+  +--------------+  |
|                                        |
|  +----------------------------------+  |
|  |          [ 登 录 ]               |  |
|  +----------------------------------+  |
|                                        |
|  * 点击验证码图片可刷新                |
|  * 密码长度不少于 6 位                 |
+----------------------------------------+
```

## 四、接口定义

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 获取验证码 | GET | `/api/auth/captcha` | 返回验证码图片和 Key |
| 用户登录 | POST | `/api/auth/login` | 校验用户名密码并返回 Token |
| 用户登出 | POST | `/api/auth/logout` | 清除登录状态 |
| 获取用户信息 | GET | `/api/auth/user-info` | 根据 Token 获取当前用户信息 |

## 五、安全需求

| 项目 | 说明 |
| ------ | ------ |
| 密码存储 | SHA-256 + 随机盐值加密，禁止明文存储 |
| 密码传输 | 前端应使用 HTTPS 传输密码 |
| 暴力破解防护 | 图形验证码有效阻止自动化破解 |
