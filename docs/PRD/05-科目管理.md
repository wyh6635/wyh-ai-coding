# PRD-05：科目管理

> 所属系统：校园信息管理系统
> 优先级：P0
> 负责人：产品/前端/后端

---

## 一、模块概述

科目管理模块负责科目信息的维护与管理，包括科目编码、名称、类别、学分、学时等属性，支持启用/停用状态管理。

## 二、功能需求

### 2.1 科目列表查询

| 项目 | 说明 |
|------|------|
| 需求描述 | 分页浏览所有科目信息 |
| 查询条件 | 关键词（编码/名称模糊匹配）、类别、状态 |
| 展示字段 | ID、科目编码、科目名称、类别、学分、学时、描述、状态、创建时间 |
| 分页规则 | 默认每页 10 条，支持翻页 |
| 排序规则 | 按 ID 倒序排列 |

### 2.2 全部启用科目查询

| 项目 | 说明 |
|------|------|
| 需求描述 | 获取所有启用状态的科目列表，供下拉选择使用 |
| 触发时机 | 成绩录入等场景需要选择科目时 |
| 返回字段 | ID、科目编码、科目名称、类别、学分、状态 |
| 业务规则 | 仅返回状态为"启用"的科目 |

### 2.3 科目详情查看

| 项目 | 说明 |
|------|------|
| 需求描述 | 查看单个科目的完整信息 |
| 触发时机 | 点击科目列表中的"查看"或科目名称 |

### 2.4 新增科目

| 项目 | 说明 |
|------|------|
| 需求描述 | 创建新的科目记录 |
| 录入字段 | 科目编码、科目名称、类别、学分、学时、描述、状态 |
| 必填字段 | 科目编码、科目名称 |
| 校验规则 | 1. 科目编码全局唯一<br>2. 科目名称全局唯一 |
| 类别选项 | 文化课、专业课、选修课（可自定义） |
| 默认值 | 学分 0.00，学时 0，状态 1（启用） |

### 2.5 修改科目信息

| 项目 | 说明 |
|------|------|
| 需求描述 | 修改已有科目的信息 |
| 可修改字段 | 科目名称、类别、学分、学时、描述、状态 |
| 校验规则 | 1. 科目必须存在<br>2. 修改科目名称时校验唯一性（排除自身） |
| 不可修改 | 科目编码（subject_code）创建后不可修改 |

### 2.6 删除科目

| 项目 | 说明 |
|------|------|
| 需求描述 | 删除科目记录（物理删除） |
| 业务规则 | 1. 有关联成绩记录的科目禁止删除<br>2. 删除前需二次确认 |
| 异常提示 | "该科目有关联数据，无法删除" |

### 2.7 科目状态管理

| 项目 | 说明 |
|------|------|
| 需求描述 | 切换科目启用/停用状态 |
| 业务规则 | 停用的科目在成绩录入时不可选择 |

## 四、字段说明

| 字段 | 类型 | 长度 | 必填 | 说明 |
|------|------|------|------|------|
| subject_code | VARCHAR | 20 | 是 | 科目编码，全局唯一 |
| subject_name | VARCHAR | 50 | 是 | 科目名称，全局唯一 |
| category | VARCHAR | 30 | 否 | 科目类别 |
| credit | DECIMAL | (5,2) | 否 | 学分 |
| total_hours | INT | — | 否 | 总学时 |
| description | VARCHAR | 500 | 否 | 科目描述 |
| status | TINYINT | — | 否 | 状态：1-启用，0-停用 |

## 五、接口定义

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 科目列表 | GET | `/api/subjects` | 分页查询科目列表 |
| 全部启用科目 | GET | `/api/subjects/all` | 返回所有启用科目 |
| 科目详情 | GET | `/api/subjects/{id}` | 查询单个科目详情 |
| 新增科目 | POST | `/api/subjects` | 创建新科目 |
| 修改科目 | PUT | `/api/subjects/{id}` | 更新科目信息 |
| 删除科目 | DELETE | `/api/subjects/{id}` | 物理删除科目 |

## 六、业务规则汇总

| 规则 | 说明 |
|------|------|
| 编码唯一 | 新增时检查，创建后不可修改 |
| 名称唯一 | 新增时检查，修改时排除自身 |
| 关联删除限制 | 有关联成绩的科目不可删除 |
| 物理删除 | 科目删除为物理删除 |
| 状态约束 | 停用科目不能录入成绩 |
