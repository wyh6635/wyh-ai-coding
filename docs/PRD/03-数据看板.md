# PRD-03：数据看板

> 所属系统：校园信息管理系统
> 优先级：P1
> 负责人：产品/前端/后端

---

## 一、模块概述

数据看板为系统首页核心展示区域，汇总展示学员、科目、成绩的关键统计指标，帮助管理人员快速掌握系统整体运行状况。

## 二、功能需求

### 2.1 学员总数统计

| 项目 | 说明 |
|------|------|
| 需求描述 | 统计并展示学员总人数和在读学员人数 |
| 展示形式 | 数字卡片（大数字 + 标签） |
| 数据来源 | student 表统计查询 |
| 业务规则 | 学员总数 = 所有未删除学员<br>在读学员 = 状态为"在读"的未删除学员 |

### 2.2 科目总数统计

| 项目 | 说明 |
|------|------|
| 需求描述 | 统计并展示启用科目数和全部科目数 |
| 展示形式 | 数字卡片 |
| 数据来源 | subject 表统计查询 |
| 业务规则 | 启用科目 = 状态为启用的科目<br>全部科目 = 所有科目（含停用） |

### 2.3 成绩记录统计

| 项目 | 说明 |
|------|------|
| 需求描述 | 统计成绩记录总数和独立考试类型数 |
| 展示形式 | 数字卡片 |
| 数据来源 | score 表统计查询 |
| 业务规则 | 考试类型数 = DISTINCT（考试类型 + 学期组合） |

### 2.4 科目成绩概览

| 项目 | 说明 |
|------|------|
| 需求描述 | 按科目分组展示平均分和成绩数量 |
| 展示形式 | 数据表格，按平均分降序排列 |
| 数据字段 | 科目编码、科目名称、成绩数量、平均分（保留 1 位小数） |
| 业务规则 | 仅展示启用状态科目<br>无成绩记录的科目平均分显示 0 |

### 2.5 最近学员动态

| 项目 | 说明 |
|------|------|
| 需求描述 | 展示最新注册的学员 |
| 展示形式 | 列表 |
| 数据字段 | 学号、姓名、班级、状态、创建时间 |
| 业务规则 | 按创建时间倒序，默认展示 5 条 |

### 2.6 最近成绩记录

| 项目 | 说明 |
|------|------|
| 需求描述 | 展示最近录入的成绩 |
| 展示形式 | 列表 |
| 数据字段 | 学员姓名、学号、科目名称、分数、等级、考试类型、学期 |
| 业务规则 | 按成绩 ID 倒序，默认展示 5 条 |

### 2.7 基础数据字典

| 项目 | 说明 |
|------|------|
| 需求描述 | 提供系统基础枚举数据 |
| 数据内容 | 1. 考试类型枚举（期中/期末/平时测验/补考）<br>2. 科目类别列表<br>3. 班级名称列表 |
| 用途 | 供其他模块下拉选择使用 |

## 四、接口定义

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 看板统计数据 | GET | `/api/dashboard/stats` | 返回学员、科目、成绩统计数 |
| 科目成绩统计 | GET | `/api/dashboard/subject-scores` | 返回各科目成绩统计 |
| 最近学员 | GET | `/api/dashboard/recent-students` | 返回最近注册学员列表 |
| 最近成绩 | GET | `/api/dashboard/recent-scores` | 返回最近成绩记录列表 |
| 考试类型枚举 | GET | `/api/dashboard/exam-types` | 返回考试类型枚举 |
| 科目类别列表 | GET | `/api/dashboard/categories` | 返回所有科目类别 |
| 班级名称列表 | GET | `/api/dashboard/class-names` | 返回所有班级名称 |
