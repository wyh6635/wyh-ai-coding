# PRD-02：首页模块

> 所属系统：校园信息管理系统
> 优先级：P1
> 负责人：产品/前端

---

## 一、模块概述

首页模块是用户登录后的第一个页面，提供系统欢迎展示和功能模块导航入口，帮助用户快速了解系统功能并进入所需模块。

## 二、功能需求

### 2.1 系统欢迎页

| 项目 | 说明 |
|------|------|
| 需求描述 | 展示系统欢迎信息，介绍系统主要功能 |
| 展示内容 | 1. 系统标题与版本号<br>2. 欢迎语<br>3. 功能模块卡片/列表 |
| 交互行为 | 点击功能卡片跳转对应模块页面 |

### 2.2 功能导航入口

| 项目 | 说明 |
|------|------|
| 需求描述 | 提供各功能模块的快捷入口 |
| 入口列表 | 1. 数据看板 → 数据统计概览<br>2. 学员管理 → 学员信息维护<br>3. 科目管理 → 科目信息维护<br>4. 成绩管理 → 成绩录入与管理<br>5. 数据查询 → 学员成绩查询 |
| 交互设计 | 卡片式布局，图标 + 标题 + 描述 |

## 四、交互说明

| 交互项 | 说明 |
|--------|------|
| 卡片点击 | 点击卡片跳转到对应功能页面 |
| 侧边栏导航 | 侧边栏同步高亮当前页面 |
| 响应式布局 | 小屏幕下卡片自动换行 |
