## 一、文档概述

### 1.1 项目背景

校园信息管理系统面向院校管理人员，旨在提供一套轻量、易用的学员信息、科目、成绩全生命周期管理解决方案。系统采用前后端分离架构，后端基于 FastAPI 提供高性能 RESTful API 服务，前端使用 Vue 3 + Element Plus 构建响应式用户界面。

### 1.2 目标用户

| 角色 | 说明 |
|------|------|
| 管理员（admin） | 拥有系统全部管理权限，负责学员、科目、成绩的日常维护 |
| 学员（student） | 可登录系统查看个人信息 |

## 四、数据实体关系

```
用户(user) ──1:N──→ 学员(student)     [通过 username 关联]
   │
   └──1:1──→ 学员成绩(view)          [查询视图]

学员(student) ──1:N──→ 成绩(score)
                           │
                           └──N:1──→ 科目(subject)
```

## 五、术语表

| 术语 | 说明 |
|------|------|
| CRUD | Create, Read, Update, Delete 增删改查 |
| JWT | JSON Web Token，一种开放标准（RFC 7519），用于在各方之间安全地传输信息 |
| Token | 令牌，系统用于验证用户身份的凭证 |
| 软删除 | 逻辑删除，通过标记字段而非物理删除数据 |
| 唯一约束 | 数据库层面保证字段值不重复的约束 |
| 外键 | 建立两个表之间数据关联的字段 |
| 联合唯一约束 | 多个字段组合后唯一的约束 |
