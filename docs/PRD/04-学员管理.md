# PRD-04：学员管理

> 所属系统：校园信息管理系统
> 优先级：P0
> 负责人：产品/前端/后端

---

## 一、模块概述

学员管理模块负责学员基本信息的全生命周期管理，包括新增、查询、修改、删除等功能，支持多条件筛选搜索和唯一性校验。

## 二、功能需求

### 2.1 学员列表查询

| 项目 | 说明 |
|------|------|
| 需求描述 | 分页浏览所有学员信息，支持多条件筛选 |
| 查询条件 | 关键词（学号/姓名模糊匹配）、班级、状态 |
| 展示字段 | ID、学号、姓名、性别、出生日期、手机号、邮箱、身份证、地址、入学日期、班级、状态、创建时间 |
| 分页规则 | 默认每页 10 条，支持翻页和跳转 |
| 排序规则 | 按 ID 倒序排列 |

### 2.2 学员详情查看

| 项目 | 说明 |
|------|------|
| 需求描述 | 查看单个学员的完整信息 |
| 触发时机 | 点击学员列表中的"查看"按钮 |
| 展示方式 | 弹窗或详情页展示 |

### 2.3 新增学员

| 项目 | 说明 |
|------|------|
| 需求描述 | 创建新的学员记录 |
| 录入字段 | 学号、姓名、性别、出生日期、手机号、邮箱、身份证、地址、入学日期、班级、状态 |
| 必填字段 | 学号、姓名、入学日期 |
| 校验规则 | 1. 学号全局唯一<br>2. 手机号全局唯一<br>3. 身份证号全局唯一<br>4. 学号、姓名不能为空 |
| 性别选项 | 男（1）、女（2）、未知（0） |
| 状态选项 | 在读（1）、休学（2）、毕业（3）、退学（4） |

### 2.4 修改学员信息

| 项目 | 说明 |
|------|------|
| 需求描述 | 修改已有学员的信息 |
| 可修改字段 | 姓名、性别、出生日期、手机号、邮箱、身份证、地址、班级、状态 |
| 校验规则 | 1. 学员必须存在<br>2. 修改手机号时校验唯一性（排除自身）<br>3. 修改身份证号时校验唯一性（排除自身） |
| 不可修改 | 学号（student_no）创建后不可修改 |

### 2.5 删除学员

| 项目 | 说明 |
|------|------|
| 需求描述 | 删除学员记录（软删除） |
| 业务规则 | 1. 采用逻辑删除，数据保留在数据库<br>2. 有关联成绩记录的学员禁止删除<br>3. 删除前需二次确认 |
| 异常提示 | "该学员有关联成绩记录，无法删除。请先删除相关成绩后再试。" |

## 四、字段说明

| 字段 | 类型 | 长度 | 必填 | 说明 |
|------|------|------|------|------|
| student_no | VARCHAR | 20 | 是 | 学号，全局唯一 |
| name | VARCHAR | 50 | 是 | 姓名 |
| gender | TINYINT | — | 否 | 性别：0-未知，1-男，2-女 |
| birth_date | DATE | — | 否 | 出生日期 |
| phone | VARCHAR | 20 | 否 | 手机号，全局唯一 |
| email | VARCHAR | 100 | 否 | 电子邮箱 |
| id_card | VARCHAR | 18 | 否 | 身份证号，全局唯一 |
| address | VARCHAR | 200 | 否 | 家庭地址 |
| enrollment_date | DATE | — | 是 | 入学日期 |
| class_name | VARCHAR | 50 | 否 | 班级名称 |
| status | TINYINT | — | 否 | 状态：1-在读，2-休学，3-毕业，4-退学 |

## 五、接口定义

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 学员列表 | GET | `/api/students` | 分页查询学员列表 |
| 学员详情 | GET | `/api/students/{id}` | 查询单个学员详情 |
| 新增学员 | POST | `/api/students` | 创建新学员 |
| 修改学员 | PUT | `/api/students/{id}` | 更新学员信息 |
| 删除学员 | DELETE | `/api/students/{id}` | 软删除学员 |

## 六、业务规则汇总

| 规则 | 说明 |
|------|------|
| 学号唯一 | 新增时检查，创建后不可修改 |
| 手机号唯一 | 新增和修改时检查，修改时排除自身 |
| 身份证唯一 | 新增和修改时检查，修改时排除自身 |
| 关联删除限制 | 有关联成绩的学员不可删除 |
| 软删除 | 删除操作不物理删除数据，仅设置 deleted 标记 |
