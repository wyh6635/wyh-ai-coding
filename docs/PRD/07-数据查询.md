# PRD-07：数据查询

> 所属系统：校园信息管理系统
> 优先级：P1
> 负责人：产品/前端/后端

---

## 一、模块概述

数据查询模块提供学员成绩的多维度检索功能，支持按学员、科目、考试类型、学期等条件进行筛选，帮助用户快速定位所需成绩信息。

## 二、功能需求

### 2.1 学员成绩查询

| 项目 | 说明 |
|------|------|
| 需求描述 | 多条件查询学员成绩数据 |
| 查询条件 | 学员、科目、考试类型、学期、关键词、班级 |
| 展示字段 | 学员学号、学员姓名、班级、科目编码、科目名称、分数、等级、考试类型、学期、考试日期 |
| 分页规则 | 默认每页 10 条 |

### 2.2 成绩筛选条件

| 筛选项 | 控件类型 | 数据来源 |
|--------|----------|----------|
| 学员 | 下拉选择 | 学员列表 |
| 科目 | 下拉选择 | 启用科目列表 |
| 考试类型 | 下拉选择 | 期中/期末/平时测验/补考 |
| 班级 | 下拉选择 | 班级名称列表 |
| 学期 | 文本输入 | 手动输入学期名称 |
| 关键词 | 文本输入 | 按学员姓名/学号模糊搜索 |

## 四、交互说明

| 交互项 | 说明 |
|--------|------|
| 查询 | 点击查询按钮，按条件筛选数据 |
| 重置 | 清空所有筛选条件，重新加载默认数据 |
| 分页 | 支持页码跳转和每页条数切换 |
| 下拉联动 | 筛选条件变化时，下拉选项自动更新 |

## 五、接口说明

本模块复用成绩管理的成绩列表查询接口，无独立后端接口。

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 成绩列表 | GET | `/api/scores` | 多条件查询成绩（复用） |
| 学员列表 | GET | `/api/students` | 学员下拉数据 |
| 科目列表 | GET | `/api/subjects/all` | 科目下拉数据 |
| 考试类型 | GET | `/api/dashboard/exam-types` | 考试类型枚举 |
| 班级列表 | GET | `/api/dashboard/class-names` | 班级下拉数据 |

## 六、与成绩管理的区别

| 对比项 | 成绩管理 | 数据查询 |
|--------|----------|----------|
| 核心功能 | 增删改查 | 仅查询 |
| 操作按钮 | 录入、批量录入、编辑、删除 | 无操作按钮 |
| 展示侧重 | 管理操作 | 数据检索 |
| 使用场景 | 管理员维护成绩 | 快速查询成绩 |
