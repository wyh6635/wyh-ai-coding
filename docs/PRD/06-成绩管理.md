# PRD-06：成绩管理

> 所属系统：校园信息管理系统
> 优先级：P0
> 负责人：产品/前端/后端

---

## 一、模块概述

成绩管理模块负责学员成绩的录入、修改、删除与统计，支持单条和批量录入，自动计算成绩等级，并提供多维度筛选查询。

## 二、功能需求

### 2.1 成绩列表查询

| 项目 | 说明 |
|------|------|
| 需求描述 | 分页浏览所有成绩记录，支持多条件筛选 |
| 查询条件 | 学员、科目、考试类型、学期、关键词（姓名/学号）、班级 |
| 展示字段 | 成绩 ID、学员学号、学员姓名、班级、科目编码、科目名称、分数、等级、考试类型、考试日期、学期、备注 |
| 分页规则 | 默认每页 10 条 |
| 排序规则 | 按成绩 ID 倒序排列 |

### 2.2 成绩详情查看

| 项目 | 说明 |
|------|------|
| 需求描述 | 查看单条成绩的完整信息 |
| 关联展示 | 同时展示学员信息和科目信息 |

### 2.3 单条成绩录入

| 项目 | 说明 |
|------|------|
| 需求描述 | 为单个学员录入一门科目的成绩 |
| 录入字段 | 学员、科目、分数、考试类型、考试日期、学期、备注 |
| 业务规则 | 1. 学员必须存在且未删除<br>2. 科目必须启用<br>3. 同一学员+同一科目+同一考试类型+同一学期不可重复<br>4. 分数范围 0-100<br>5. 自动计算成绩等级 |
| 等级规则 | A: ≥90, B: ≥80, C: ≥70, D: ≥60, F: <60 |

### 2.4 批量成绩录入

| 项目 | 说明 |
|------|------|
| 需求描述 | 一次为同一学员录入多个科目成绩 |
| 录入方式 | 学员选择 + 多行科目成绩表格 |
| 业务规则 | 1. 学员必须存在<br>2. 每条成绩独立校验<br>3. 支持部分成功部分失败<br>4. 返回成功数量和失败详情 |

### 2.5 修改成绩

| 项目 | 说明 |
|------|------|
| 需求描述 | 修改已有成绩的信息 |
| 可修改字段 | 分数、考试类型、考试日期、学期、备注 |
| 业务规则 | 1. 成绩必须存在<br>2. 修改分数时自动重算等级<br>3. 分数范围 0-100 |

### 2.6 删除成绩

| 项目 | 说明 |
|------|------|
| 需求描述 | 删除单条成绩记录 |
| 业务规则 | 物理删除，删除前需二次确认 |

### 2.7 成绩统计汇总

| 项目 | 说明 |
|------|------|
| 需求描述 | 按科目统计成绩数据 |
| 统计内容 | 每个科目的成绩数量、平均分、最高分、最低分 |
| 展示形式 | 数据表格 |
| 排序规则 | 按平均分降序排列 |

## 四、字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| student_id | BIGINT | 是 | 学员 ID（外键） |
| subject_id | BIGINT | 是 | 科目 ID（外键） |
| score_value | DECIMAL(5,2) | 是 | 成绩分数，范围 0-100 |
| grade_level | CHAR(2) | 自动 | 等级：A/B/C/D/F |
| exam_type | TINYINT | 是 | 考试类型：1-期中，2-期末，3-平时测验，4-补考 |
| exam_date | DATE | 否 | 考试日期 |
| term | VARCHAR(20) | 否 | 学期 |
| remark | VARCHAR(200) | 否 | 备注 |

## 五、接口定义

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 成绩列表 | GET | `/api/scores` | 分页查询成绩列表 |
| 成绩详情 | GET | `/api/scores/{id}` | 查询单条成绩详情 |
| 单条录入 | POST | `/api/scores` | 录入单条成绩 |
| 批量录入 | POST | `/api/scores/batch` | 批量录入多个科目成绩 |
| 修改成绩 | PUT | `/api/scores/{id}` | 更新成绩信息 |
| 删除成绩 | DELETE | `/api/scores/{id}` | 物理删除成绩 |
| 成绩统计 | GET | `/api/scores/stats/summary` | 成绩统计汇总数据 |

## 六、业务规则汇总

| 规则 | 说明 |
|------|------|
| 分数范围 | 0-100 分 |
| 自动等级 | 根据分数自动计算，修改时重算 |
| 唯一性校验 | 同一学员+科目+考试类型+学期不可重复 |
| 学员存在校验 | 录入时校验学员存在且未删除 |
| 科目启用校验 | 录入时校验科目为启用状态 |
| 批量容错 | 批量录入支持部分成功部分失败 |
